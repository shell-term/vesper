# Vesper（ヴェスパー）

元のモデルの精度を保ち、GPU・RAM・SSDを組み合わせて大きなMoEモデルを動かすためのプロジェクトです。
最初の対象はDeepSeek-V4.1-Flash-1017、RTX 4090＋RTX 3080 Tiです。

現在は**expert一個分を動かせる検証用実装**です。まだ文章生成はできません。
元の重みを保持し、公式実装と直接比較しています。

| 検証対象 | 範囲 | 判定 |
| --- | --- | --- |
| RTX 4090のFP8演算 | expert全体・128条件 | 最終655,360出力と検証した中間値がすべてビット単位で一致 |
| RTX 3080 TiのBF16演算候補 | W1の128行・8入力 | 1,024出力中14個不一致・未合格 |

expert全体の検証には、三つの行列演算、学習時のクリップ、重み付きSwiGLU、途中の丸めを含みます。
入力の大きさと重み付けを変え、GPU上の重みと作業領域を繰り返し使いました。
元の重みは約18.8MB、明示的なGPU確保量は約18.9MBです。CUDAや公式比較環境の使用量は別にかかります。

3080 Tiの差は32要素の積和の時点で発生しています。BF16への置き換えだけでは公式のFP8演算を再現できませんでした。
詳細と省略していない測定データは[expert検証レポート](docs/expert-validation.md)にあります。
層全体、モデル全体の品質、文章生成の速度は未検証です。

推論全体のRAM上限96GiB・システムの空き32GiBを初期設計としています。
これは将来のエンジンに求める条件であり、推論全体のメモリ制御が実装済みという意味ではありません。
現在の検証は小さなバッファで行い、他のアプリや推論エンジンを停止しません。

追加の非可逆な量子化、expertの削除、キャッシュに合わせたルーティング変更は採用しません。
公式モデルに元から含まれるFP4/FP8を保持し、途中の丸め処理も確認します。

実行方法と詳細は[英語README](README.md)、進捗の判断基準は[検証計画](docs/validation.md)を参照してください。
公開用コードにモデルの重みやローカル環境のパスは含めません。MITライセンスです。
