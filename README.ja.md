# Vesper（ヴェスパー）

元のモデルの精度を保ち、GPU・RAM・SSDを組み合わせて大きなMoEモデルを動かすためのプロジェクトです。
最初の対象はDeepSeek-V4.1-Flash-1017、RTX 4090＋RTX 3080 Tiです。

現在は**検証用の最小実装**です。まだ文章生成はできません。
両GPUでFP4/FP8の形式変換と小さな行列演算を独立した数値仕様と比較し、一致しました。
さらに、元の重みの一部を使い、公式カーネルと直接比較しました。

| 検証対象 | 8入力・計1,024出力の不一致数 | 判定 |
| --- | --- | --- |
| RTX 4090のFP8演算 | 0 | 今回の範囲でビット単位に一致 |
| RTX 3080 TiのBF16演算候補 | 14 | 未合格・推論には採用しない |

対象はW1行列の128行だけです。expert全体、モデル全体の品質、文章生成の速度は未検証です。
詳細と省略していない測定データは[初回検証レポート](docs/first-probe.md)にあります。

推論全体のRAM上限96GiB・システムの空き32GiBを初期設計としています。
これは将来のエンジンに求める条件であり、推論全体のメモリ制御が実装済みという意味ではありません。
現在の検証は小さなバッファで行い、他のアプリや推論エンジンを停止しません。

追加の非可逆な量子化、expertの削除、キャッシュに合わせたルーティング変更は採用しません。
公式モデルに元から含まれるFP4/FP8を保持し、途中の丸め処理も確認します。

実行方法と詳細は[英語README](README.md)、進捗の判断基準は[検証計画](docs/validation.md)を参照してください。
